Course Description

This course introduces the field of machine learning, with emphasis on the probabilistic models that dominate contemporary applications: how computers learn from examples, classification and regression, and supervised and unsupervised learning, together with the statistical models and computational methods behind them.

The course is about fundamentals: every method is derived, worked by hand on small numbers, and implemented from scratch before you use a library version. It is also about now: each lecture closes by showing where its classical idea lives in 2026–27 industry and research — the softmax regression inside a language model, the nearest-neighbor search behind recommendations, the gradient boosting inside fraud detection, the diffusion models behind image generators, the reinforcement learning behind reasoning models. The arc runs from k-nearest neighbors in week one to foundation models in April, measured all semester on one shared benchmark, the Fashion-MNIST scoreboard.

The course is lecture-oriented, with four substantial programming assignments, an in-class midterm, and a final project (teams of 1–4) presented on the three presentation days. Prerequisites: STAT 3850, CSCI 2100, and MATH 2530. Linear algebra beyond the basics is not assumed — Lectures 3–4 teach the math toolkit the course uses.

See the class schedule for the lecture-by-lecture calendar with readings and due dates.

Learning Goals

  1. Formulate a prediction problem as learning from data — features, labels, hypothesis class, loss, and evaluation — and explain the difference between fitting the training data and generalizing.
  2. Derive and implement core supervised methods from scratch — nearest neighbors, linear and logistic regression, regularized models, Naive Bayes, decision trees — and explain how kernels, SVMs, and ensembles extend them.
  3. Connect losses to likelihoods: explain maximum likelihood, MAP estimation, and Bayesian inference, and use the probabilistic view to choose and justify a model.
  4. Apply unsupervised methods — k-means, Gaussian mixtures with EM, PCA, embeddings, matrix factorization — and interpret their output honestly.
  5. Build, train, and debug neural networks, from backpropagation by hand to convolutional networks in PyTorch, and explain how self-supervised learning, generative models, and reinforcement learning power today's foundation models.
  6. Evaluate models rigorously — cross-validation, appropriate metrics, leakage checks, fairness criteria, and distribution shift — and recognize when a reported number should not be trusted.
  7. Conduct and communicate an original ML project: formulate a question, run experiments against baselines, and present findings in a written report and a talk.

Materials

All required materials are free.

  • [ISLP] James, Witten, Hastie, Tibshirani & Taylor, An Introduction to Statistical Learning with Applications in Python (2023) — statlearning.com
  • [PML] Murphy, Probabilistic Machine Learning: An Introduction (2022) — probml.github.io/pml-book
  • [MML] Deisenroth, Faisal & Ong, Mathematics for Machine Learning (2020) — mml-book.github.io
  • [UDL] Prince, Understanding Deep Learning (2023) — udlbook.github.io/udlbook
  • [S&B] Sutton & Barto, Reinforcement Learning: An Introduction, 2nd ed. (2018) — incompleteideas.net
  • Papers and posts for the “Now” segments and the modern-ML lectures — listed on the class schedule.

Assignments are sized for Google Colab. A GPU helps only in HW4 and in some projects, and Colab provides one.
